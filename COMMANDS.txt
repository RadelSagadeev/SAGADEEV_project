1.git status
проверяет статус репозитория. 
Как я понимаю, проверяет прошла синхронизация файлов или нет.

2.git init 
Инициализирует репозиторий.
Создает скрыту слежебную папку git

3.git add <file>
Добавляет файл или изменеия в область подготовки будущего коммита

4. git commit -m "Сообщение любое вообще"
Публикует файл с сообщением как новый коммит.

5. git --version
Так можно узнать версию нашего ГИТа
